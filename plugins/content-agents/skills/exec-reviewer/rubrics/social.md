# Rubric: corporate social

## Must-haves
- **SOC-001** First line is the most interesting true thing; no throat-clearing.
- **SOC-002** No buzzwords (VOI-004); numerals for numbers.
- **SOC-003** One idea per post; one link or CTA.
- **SOC-004** LinkedIn can be longer and more substantive; X stays tight.
- **SOC-005** Stats quoted exactly (MSG-006); no competitor names (MSG-011).
- **SOC-006** Derivative posts stay faithful to the source piece's message and numbers.
- **SOC-007** No more than one exclamation point, never on product promotion.
